# Recreate

A responsive pricing page built with **HTML5** and **Tailwind CSS**. This project recreates a modern pricing section commonly found on SaaS and business websites while focusing on clean design, responsive layouts, and reusable UI components.

##  Live Preview

Clone the repository and open `recreate.html` in your browser to view the project.

##  Project Overview

This project includes:

* Three responsive pricing cards
* Clean and modern UI
* Mobile-first responsive layout
* Tailwind CSS utility classes
* Consistent spacing and typography
* Interactive call-to-action buttons

##  Technologies Used

* HTML5
* Tailwind CSS (CDN)

##  Getting Started

### Clone the repository

```bash
git clone https://github.com/abrahamm2/Recreate.git
```

### Open the project

Navigate to the project folder and open:

```text
recreate.html
```

in your preferred web browser.

No installation or build tools are required.
